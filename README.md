# Laith’s English Studio

A quiet, offline English practice tool for an eight-year-old, designed for live tutoring over Microsoft Teams screen sharing.

**Website:** [Laith’s English Studio](https://aburomoh.github.io/Laith_Lessons/) — planned GitHub Pages address; publication is pending, so this link is not yet live.

## Start

For uploading or pushing this project yourself, see [the GitHub handoff guide](docs/GITHUB_UPLOAD.md).

Download the repository and open `learning-tool/index.html` in your browser. On Windows, double-click `Open English Studio.cmd`.

The teaching screen shows one question, answer choices, a tutor image and three controls: **back · answer · next**. A small **⋯** button opens tutor tools: topics, hints, text size, expressions, source notes and progress. Press **T** to open those tools from the keyboard.

Laith answers aloud. The tutor operates the screen. Responses stay hidden until a choice is selected or Answer is pressed. No account, internet connection or installation is required to teach.

## Phones and tablets

The interface adapts to iPhone, iPad and Android screen sizes, with touch controls and scrollable dialogs. For access from another device, use the GitHub Pages link once publication is enabled; a computer’s 127.0.0.1 preview address is local to that computer. Progress remains separate in each browser/device.

## Included

- 152 questions across nine topics, grounded in the 13 selected exam pages.
- Clearly distinguished source-based and extra practice in tutor tools.
- Short feedback, expressive tutor poses, mixed practice and a revisit queue.
- Local browser progress and TypeScript/CSS source.

All 28 original page photographs are included in the repository with the owner’s approval, alongside 18 tutor portraits and 3 concept illustrations. Keep the photographs at the repository root so the local source-photo viewer can find them. The lightweight GitHub Pages package excludes the original photographs; the app works without them.

See [the teaching and development guide](learning-tool/README.md) for keyboard shortcuts, source notes and build instructions.
